# Full-Stack Data Science, GenAI and Agentic AI

Learning materials and practice files for Python, data structures, data science, generative AI, and agentic AI.

## Contents

- `01_Python/` - Python learning notebooks
  - `variable.ipynb` - Variables and basic Python concepts
  - `string_with_slicing.ipynb` - Strings and slicing
- `data_structures_info.html` - Data structures reference notes
- `data_structures_complete_course.html` - Complete data structures course material
- `test.py` - Python practice file

## Getting Started

1. Install Python 3.10 or newer.
2. Install Jupyter if needed:

   ```powershell
   python -m pip install jupyter
   ```

3. Start Jupyter from the project folder:

   ```powershell
   jupyter notebook
   ```

4. Open a notebook from `01_Python/` and run the cells.

The HTML files can be opened directly in a web browser.

## Git Notes

Jupyter checkpoint files, Python cache files, virtual environments, test artifacts, and build output are excluded by `.gitignore`.
