1. Introduction to Data Structures Beginner

What Are Data Structures?

A data structure is a specialized format for organizing, processing, retrieving, and storing data. It's a way to arrange data so that it can be accessed and modified efficiently. The choice of data structure can significantly impact the performance, scalability, and memory usage of your application.

Why Are Data Structures Important?

  • Efficiency: Proper data structures enable algorithms to run faster
  • Memory Management: Optimal memory usage and allocation
  • Problem Solving: Different problems require different data structures
  • Code Quality: Well-organized data structures lead to cleaner code
  • Scalability: Handle large datasets effectively

Classification of Data Structures

  • Primitive: int, float, char, boolean
  • Linear: Array, List, Stack, Queue
  • Non-Linear: Tree, Graph, Heap

2. Arrays & Lists Beginner

Arrays

An array is a collection of elements of the same type stored in contiguous memory locations. Each element can be accessed by its index position.

Key Characteristics:

  • ✓ Fast access by index: O(1)
  • ✓ Simple to understand and implement
  • ✗ Fixed size in most languages
  • ✗ Slow insertion/deletion: O(n)
  • ✗ Must be contiguous in memory
📌 Example 1: Basic Array Operations
# Python list (Dynamic Array) numbers = [10, 20, 30, 40, 50] # Access elements by index print(numbers[0]) # Output: 10 print(numbers[-1]) # Output: 50 (Last element) # Modify element numbers[2] = 35 # Change 30 to 35 # Add element numbers.append(60) # O(1) amortized # Insert at position numbers.insert(1, 15) # O(n) - shifts elements # Remove element numbers.pop() # Remove last: O(1) numbers.pop(2) # Remove at index: O(n) # Print all print(numbers) # [10, 15, 20, 35, 40]
📌 Example 2: 2D Arrays (Matrix)
# 2D Array matrix = [ [1, 2, 3], [4, 5, 6], [7, 8, 9] ] # Access element print(matrix[0][1]) # Output: 2 # Iterate through matrix for row in matrix: for element in row: print(element, end=" ") # Output: 1 2 3 4 5 6 7 8 9 # Transpose transpose = [[matrix[j][i] for j in range(len(matrix))] for i in range(len(matrix[0]))]

Dynamic Arrays (Lists in Python)

A dynamic array can grow or shrink as needed. When capacity is exceeded, it allocates more memory and copies existing elements. This amortizes the insertion cost to O(1) on average.

Types of Arrays:

  • Static Arrays: Fixed size (C, C++)
  • Dynamic Arrays: Variable size (Python lists, Java ArrayList)
  • Single-dimensional: 1D array
  • Multi-dimensional: 2D, 3D arrays (matrices, cubes)
  • Jagged Arrays: Arrays with unequal row sizes
Real-World Applications:
  • Image processing (pixel arrays)
  • Database indexing
  • Cache storage
  • Sorting algorithms input
  • Game boards and grids

3. Linked Lists Beginner

Definition

A linked list is a linear data structure where elements (called nodes) are linked together using pointers or references. Each node contains data and a link to the next node.

Key Characteristics:

  • ✓ Dynamic size - grows as needed
  • ✓ Efficient insertion/deletion if position known: O(1)
  • ✗ Slow sequential access: O(n)
  • ✗ Extra memory for pointers
  • ✗ No random access by index

Types of Linked Lists:

  • Singly Linked List: Each node points to next node only
  • Doubly Linked List: Each node points to both next and previous
  • Circular Linked List: Last node points back to first
  • Circular Doubly Linked List: Combination of above two
📌 Example 1: Singly Linked List
class Node: def __init__(self, data): self.data = data self.next = None class LinkedList: def __init__(self): self.head = None # Insert at beginning def insert_at_head(self, data): new_node = Node(data) new_node.next = self.head self.head = new_node # Insert at end def insert_at_end(self, data): new_node = Node(data) if not self.head: self.head = new_node return current = self.head while current.next: current = current.next current.next = new_node # Traverse and print def display(self): current = self.head while current: print(current.data, end=" -> ") current = current.next print("None") # Delete node def delete(self, data): if not self.head: return if self.head.data == data: self.head = self.head.next return current = self.head while current.next: if current.next.data == data: current.next = current.next.next return current = current.next # Usage ll = LinkedList() ll.insert_at_end(1) ll.insert_at_end(2) ll.insert_at_end(3) ll.insert_at_head(0) ll.display() # Output: 0 -> 1 -> 2 -> 3 -> None ll.delete(2) ll.display() # Output: 0 -> 1 -> 3 -> None
📌 Example 2: Doubly Linked List
class DNode: def __init__(self, data): self.data = data self.next = None self.prev = None class DoublyLinkedList: def __init__(self): self.head = None def insert_at_end(self, data): new_node = DNode(data) if not self.head: self.head = new_node return current = self.head while current.next: current = current.next current.next = new_node new_node.prev = current def display_forward(self): current = self.head while current: print(current.data, end=" <-> ") current = current.next print("None") def display_backward(self): current = self.head while current.next: current = current.next while current: print(current.data, end=" <-> ") current = current.prev print("None") # Usage dll = DoublyLinkedList() dll.insert_at_end(1) dll.insert_at_end(2) dll.insert_at_end(3) dll.display_forward() # 1 <-> 2 <-> 3 <-> None dll.display_backward() # 3 <-> 2 <-> 1 <-> None
Real-World Applications:
  • Browser history (back/forward navigation)
  • Music playlists (previous/next songs)
  • Undo/Redo functionality
  • Memory management in OS
  • Polynomial representation

4. Stacks Beginner

Definition

A stack is a linear data structure that follows the LIFO (Last-In-First-Out) principle. The last element added is the first one to be removed. Think of a stack of plates—you add and remove from the top.

Key Characteristics:

  • ✓ O(1) push and pop operations
  • ✓ Simple LIFO logic
  • ✓ Space efficient
  • ✗ Limited access (only top element)
  • ✗ No random access

Operations

  • Push: Add element to top - O(1)
  • Pop: Remove top element - O(1)
  • Peek/Top: View top element - O(1)
  • IsEmpty: Check if stack is empty - O(1)
📌 Example 1: Stack Implementation
class Stack: def __init__(self): self.items = [] def push(self, item): """Add item to top""" self.items.append(item) def pop(self): """Remove and return top item""" if not self.is_empty(): return self.items.pop() return None def peek(self): """View top item without removing""" if not self.is_empty(): return self.items[-1] return None def is_empty(self): """Check if stack is empty""" return len(self.items) == 0 def size(self): """Get stack size""" return len(self.items) def display(self): """Display stack""" print("Stack (top to bottom):", self.items[::-1]) # Usage stack = Stack() stack.push(10) stack.push(20) stack.push(30) stack.display() # Stack (top to bottom): [30, 20, 10] print(stack.peek()) # 30 print(stack.pop()) # 30 (removes it) print(stack.size()) # 2
📌 Example 2: Check Balanced Parentheses
def is_balanced(expression): """Check if parentheses are balanced using stack""" stack = [] pairs = {'(': ')', '[': ']', '{': '}'} for char in expression: if char in pairs: stack.append(char) # Push opening bracket elif char in pairs.values(): if not stack: return False if pairs[stack.pop()] != char: return False return len(stack) == 0 # Test print(is_balanced("({[]})")) # True print(is_balanced("({[}])")) # False print(is_balanced("({[]})()")) # True print(is_balanced("({[]}))(")) # False

Types of Stacks:

  • Array-based Stack: Uses array for storage
  • Linked List-based Stack: Uses linked list
  • Recursive Stack: Call stack in function calls
  • Double-ended Stack (Deque): Operations at both ends
Real-World Applications:
  • Undo/Redo in text editors
  • Browser back button history
  • Function call stack
  • Expression evaluation (postfix to infix)
  • DFS (Depth-First Search) algorithm
  • Backtracking in problems

5. Queues Beginner

Definition

A queue is a linear data structure that follows the FIFO (First-In-First-Out) principle. The first element added is the first one to be removed. Think of a line at a ticket counter.

Key Characteristics:

  • ✓ O(1) enqueue and dequeue
  • ✓ Simple FIFO logic
  • ✓ Fair ordering
  • ✗ Limited access
  • ✗ No random access

Operations

  • Enqueue: Add element to rear - O(1)
  • Dequeue: Remove from front - O(1)
  • Front: View front element - O(1)
  • IsEmpty: Check if queue is empty - O(1)

Types of Queues:

  • Simple Queue: Standard FIFO queue
  • Circular Queue: Rear connects to front
  • Double-Ended Queue (Deque): Operations at both ends
  • Priority Queue: Elements processed by priority
📌 Example 1: Simple Queue
from collections import deque # Using deque (efficient queue) queue = deque() # Enqueue (add to right) queue.append(1) queue.append(2) queue.append(3) queue.append(4) print("Queue:", list(queue)) # [1, 2, 3, 4] # Dequeue (remove from left) front = queue.popleft() print(f"Dequeued: {front}") # 1 print("Queue:", list(queue)) # [2, 3, 4] # Check front print(f"Front element: {queue[0]}") # 2 # Manual Queue Implementation class Queue: def __init__(self): self.items = [] def enqueue(self, item): self.items.append(item) def dequeue(self): if not self.is_empty(): return self.items.pop(0) return None def front(self): if not self.is_empty(): return self.items[0] return None def is_empty(self): return len(self.items) == 0 def display(self): print("Queue (front to rear):", self.items) q = Queue() q.enqueue(10) q.enqueue(20) q.enqueue(30) q.display() # [10, 20, 30] q.dequeue() q.display() # [20, 30]
📌 Example 2: Priority Queue
import heapq class PriorityQueue: def __init__(self): self.items = [] def enqueue(self, item, priority): """Add item with priority (lower number = higher priority)""" heapq.heappush(self.items, (priority, item)) def dequeue(self): """Remove and return highest priority item""" if self.items: return heapq.heappop(self.items)[1] return None def display(self): print("Queue:", self.items) pq = PriorityQueue() pq.enqueue("Task A", 3) pq.enqueue("Task B", 1) pq.enqueue("Task C", 2) pq.display() # [(1, 'Task B'), (3, 'Task A'), (2, 'Task C')] print(pq.dequeue()) # Task B (priority 1) print(pq.dequeue()) # Task C (priority 2)
📌 Example 3: Circular Queue
class CircularQueue: def __init__(self, size): self.size = size self.queue = [None] * size self.front = -1 self.rear = -1 def enqueue(self, item): if (self.rear + 1) % self.size == self.front: print("Queue is full!") return if self.front == -1: self.front = 0 self.rear = (self.rear + 1) % self.size self.queue[self.rear] = item def dequeue(self): if self.front == -1: print("Queue is empty!") return None item = self.queue[self.front] if self.front == self.rear: self.front = self.rear = -1 else: self.front = (self.front + 1) % self.size return item def display(self): if self.front == -1: print("Queue is empty!") return print("Circular Queue:", end=" ") i = self.front while i != self.rear: print(self.queue[i], end=" ") i = (i + 1) % self.size print(self.queue[self.rear]) cq = CircularQueue(5) cq.enqueue(10) cq.enqueue(20) cq.enqueue(30) cq.display() # 10 20 30 print(cq.dequeue()) # 10 cq.display() # 20 30
Real-World Applications:
  • Print job scheduling
  • CPU task scheduling
  • Breadth-First Search (BFS)
  • Customer service queues
  • Message passing systems
  • Traffic light systems

6. Hash Tables (Dictionaries) Intermediate

Definition

A hash table is a data structure that maps keys to values using a hash function. It provides very fast average-case lookup, insertion, and deletion by computing an index into an array of buckets or slots.

Key Characteristics:

  • ✓ Average O(1) for search, insert, delete
  • ✓ Efficient key-value mapping
  • ✓ Flexible key and value types
  • ✗ Unordered (in older Python versions)
  • ✗ Can have hash collisions
  • ✗ Worst case O(n) if many collisions

Hash Function

A hash function converts a key into an array index. Good hash functions:

  • Distribute keys uniformly across array
  • Are deterministic (same input = same output)
  • Are fast to compute
  • Minimize collisions

Hash Table Types:

  • Direct Addressing: Key is index directly
  • Closed Hashing (Open Addressing): Collision resolved within table
  • Open Hashing (Chaining): Each slot contains linked list of items

Collision Resolution Methods:

  • Chaining: Store colliding items in linked list
  • Linear Probing: Find next empty slot
  • Quadratic Probing: Use quadratic formula to find slot
  • Double Hashing: Use second hash function
📌 Example 1: Dictionary Operations (Python)
# Dictionary creation student = { "name": "John", "age": 20, "grade": "A", "courses": ["Math", "Physics"] } # Access values print(student["name"]) # John print(student.get("age")) # 20 print(student.get("email", "N/A")) # N/A (default value) # Add/update student["email"] = "john@example.com" student["age"] = 21 # Delete del student["grade"] # or student.pop("courses") # Check key existence if "name" in student: print("Name exists") # Iterate for key, value in student.items(): print(f"{key}: {value}") # Dictionary methods print(student.keys()) # dict_keys([...]) print(student.values()) # dict_values([...]) print(len(student)) # 3 student.clear() # Remove all items
📌 Example 2: Hash Table Implementation with Chaining
class HashTable: def __init__(self, size=10): self.size = size self.table = [[] for _ in range(size)] # Array of lists def hash_function(self, key): """Simple hash function""" return hash(key) % self.size def insert(self, key, value): """Insert key-value pair""" index = self.hash_function(key) # Check if key exists and update for i, (k, v) in enumerate(self.table[index]): if k == key: self.table[index][i] = (key, value) return # Add new pair self.table[index].append((key, value)) def search(self, key): """Search for value by key""" index = self.hash_function(key) for k, v in self.table[index]: if k == key: return v return None def delete(self, key): """Delete key-value pair""" index = self.hash_function(key) for i, (k, v) in enumerate(self.table[index]): if k == key: self.table[index].pop(i) return True return False def display(self): """Display hash table""" for i, bucket in enumerate(self.table): if bucket: print(f"Index {i}: {bucket}") # Usage ht = HashTable(7) ht.insert("apple", 5) ht.insert("banana", 3) ht.insert("cherry", 8) ht.insert("date", 2) print(ht.search("apple")) # 5 ht.display() ht.delete("banana") print(ht.search("banana")) # None
Real-World Applications:
  • Database indexing
  • Caching (CPU cache, web cache)
  • Symbol table in compilers
  • Spell checking
  • Counting word frequency
  • Finding duplicates

7. Sets Beginner

Definition

A set is an unordered collection of unique elements. It's based on hash table and provides fast membership testing and eliminates duplicate values.

Key Characteristics:

  • ✓ O(1) average membership testing
  • ✓ No duplicates
  • ✓ Supports mathematical set operations
  • ✗ Unordered
  • ✗ No indexing
📌 Example 1: Set Operations
# Create sets set1 = {1, 2, 3, 4, 5} set2 = {4, 5, 6, 7, 8} set3 = set() # Empty set # Add elements set3.add(10) set3.update([20, 30, 40]) # Remove elements set3.remove(20) # Raises KeyError if not found set3.discard(30) # Doesn't raise error # Membership testing print(1 in set1) # True # Union union = set1 | set2 print(union) # {1, 2, 3, 4, 5, 6, 7, 8} # Intersection intersection = set1 & set2 print(intersection) # {4, 5} # Difference difference = set1 - set2 print(difference) # {1, 2, 3} # Symmetric Difference sym_diff = set1 ^ set2 print(sym_diff) # {1, 2, 3, 6, 7, 8} # Subset/Superset print(set1.issubset(set2)) # False print({4, 5}.issubset(set1)) # True # Iterate for element in set1: print(element, end=" ")
📌 Example 2: Remove Duplicates
# Remove duplicates from list numbers = [1, 2, 2, 3, 3, 3, 4, 5, 5] unique = list(set(numbers)) print(unique) # [1, 2, 3, 4, 5] # Preserve order (Python 3.7+) unique_ordered = list(dict.fromkeys(numbers)) print(unique_ordered) # [1, 2, 3, 4, 5] # Count unique elements print(len(set(numbers))) # 5
Real-World Applications:
  • Removing duplicates
  • Finding common elements
  • Testing membership
  • Database queries (UNION, INTERSECT)
  • Spell checking unique words

8. Trees Intermediate

Definition

A tree is a hierarchical data structure consisting of nodes connected by edges. It has a root node and each node can have multiple children. Trees are recursive by nature and are used extensively in databases, file systems, and algorithms.

Key Terminology:

  • Root: Top node with no parent
  • Parent: Node with children
  • Child: Node with a parent
  • Leaf: Node with no children
  • Height: Distance from node to farthest leaf
  • Depth: Distance from root to node

Types of Trees:

  • Binary Tree: Each node has at most 2 children
  • Binary Search Tree: Left < parent < right
  • AVL Tree: Self-balancing BST
  • Red-Black Tree: Balanced with coloring
  • B-Tree: Multi-way search tree
  • Trie: Prefix tree for strings
  • Segment Tree: For range queries
📌 Example 1: Binary Tree
class TreeNode: def __init__(self, value): self.value = value self.left = None self.right = None class BinaryTree: def __init__(self): self.root = None # Preorder: Root -> Left -> Right def preorder(self, node): if node: print(node.value, end=" ") self.preorder(node.left) self.preorder(node.right) # Inorder: Left -> Root -> Right def inorder(self, node): if node: self.inorder(node.left) print(node.value, end=" ") self.inorder(node.right) # Postorder: Left -> Right -> Root def postorder(self, node): if node: self.postorder(node.left) self.postorder(node.right) print(node.value, end=" ") def level_order(self): """BFS traversal""" if not self.root: return queue = [self.root] while queue: node = queue.pop(0) print(node.value, end=" ") if node.left: queue.append(node.left) if node.right: queue.append(node.right) def height(self, node): """Calculate tree height""" if not node: return -1 return 1 + max(self.height(node.left), self.height(node.right)) # Build tree # 1 # / \ # 2 3 # / \ # 4 5 tree = BinaryTree() tree.root = TreeNode(1) tree.root.left = TreeNode(2) tree.root.right = TreeNode(3) tree.root.left.left = TreeNode(4) tree.root.left.right = TreeNode(5) print("Preorder: ", end="") tree.preorder(tree.root) # 1 2 4 5 3 print("\nInorder: ", end="") tree.inorder(tree.root) # 4 2 5 1 3 print("\nPostorder: ", end="") tree.postorder(tree.root) # 4 5 2 3 1 print("\nLevel Order: ", end="") tree.level_order() # 1 2 3 4 5 print(f"\nHeight: {tree.height(tree.root)}") # 2
📌 Example 2: Binary Search Tree
class BST: def __init__(self): self.root = None def insert(self, value): """Insert value maintaining BST property""" if self.root is None: self.root = TreeNode(value) else: self._insert_helper(self.root, value) def _insert_helper(self, node, value): if value < node.value: if node.left: self._insert_helper(node.left, value) else: node.left = TreeNode(value) else: if node.right: self._insert_helper(node.right, value) else: node.right = TreeNode(value) def search(self, value): """Search for value in BST""" return self._search_helper(self.root, value) def _search_helper(self, node, value): if not node: return False if value == node.value: return True elif value < node.value: return self._search_helper(node.left, value) else: return self._search_helper(node.right, value) def delete(self, value): """Delete value from BST""" self.root = self._delete_helper(self.root, value) def _delete_helper(self, node, value): if not node: return None if value < node.value: node.left = self._delete_helper(node.left, value) elif value > node.value: node.right = self._delete_helper(node.right, value) else: # Node found if not node.left: return node.right if not node.right: return node.left # Node with two children min_larger_node = self._find_min(node.right) node.value = min_larger_node.value node.right = self._delete_helper(node.right, min_larger_node.value) return node def _find_min(self, node): current = node while current.left: current = current.left return current # Usage bst = BST() values = [50, 30, 70, 20, 40, 60, 80] for val in values: bst.insert(val) print(bst.search(40)) # True print(bst.search(100)) # False
Real-World Applications:
  • File systems (directory structure)
  • Database indexing (B-trees)
  • DOM structure in HTML
  • Expression evaluation
  • Syntax parsing in compilers
  • Autocomplete (Trie)

9. Graphs Intermediate

Definition

A graph is a collection of nodes (vertices) and edges connecting pairs of nodes. It's used to represent networks, social connections, maps, and many other real-world relationships.

Key Terminology:

  • Vertex/Node: A point in the graph
  • Edge: Connection between two vertices
  • Weight: Cost/distance associated with edge
  • Degree: Number of edges connected to vertex
  • Path: Sequence of vertices
  • Cycle: Path that starts and ends at same vertex

Types of Graphs:

  • Directed Graph: Edges have direction (A → B)
  • Undirected Graph: Edges have no direction
  • Weighted Graph: Edges have weights/costs
  • Unweighted Graph: All edges equal weight
  • Cyclic Graph: Contains cycles
  • Acyclic Graph (DAG): No cycles

Graph Representations

  • Adjacency List: Space: O(V+E), Fast for sparse graphs
  • Adjacency Matrix: Space: O(V²), Fast for dense graphs
  • Edge List: Simple but slow lookup
📌 Example 1: Graph Representation
# Adjacency List Representation graph_list = { 'A': ['B', 'C'], 'B': ['A', 'D', 'E'], 'C': ['A', 'F'], 'D': ['B'], 'E': ['B', 'F'], 'F': ['C', 'E'] } # Adjacency Matrix Representation # Vertices: A=0, B=1, C=2, D=3, E=4, F=5 graph_matrix = [ [0, 1, 1, 0, 0, 0], # A [1, 0, 0, 1, 1, 0], # B [1, 0, 0, 0, 0, 1], # C [0, 1, 0, 0, 0, 0], # D [0, 1, 0, 0, 0, 1], # E [0, 0, 1, 0, 1, 0] # F ] # Weighted Graph weighted_graph = { 'A': [('B', 4), ('C', 2)], 'B': [('A', 4), ('D', 5), ('E', 10)], 'C': [('A', 2), ('F', 3)], 'D': [('B', 5)], 'E': [('B', 10), ('F', 1)], 'F': [('C', 3), ('E', 1)] } print("Adjacency List:", graph_list) print("Neighbors of B:", graph_list['B'])
📌 Example 2: Graph Traversals
class Graph: def __init__(self, vertices): self.V = vertices self.graph = {} for i in range(vertices): self.graph[i] = [] def add_edge(self, u, v): self.graph[u].append(v) def dfs(self, start): """Depth-First Search using stack""" visited = set() stack = [start] result = [] while stack: vertex = stack.pop() if vertex not in visited: visited.add(vertex) result.append(vertex) stack.extend(reversed(self.graph[vertex])) return result def bfs(self, start): """Breadth-First Search using queue""" visited = set([start]) queue = [start] result = [] while queue: vertex = queue.pop(0) result.append(vertex) for neighbor in self.graph[vertex]: if neighbor not in visited: visited.add(neighbor) queue.append(neighbor) return result def dfs_recursive(self, vertex, visited, result): """DFS using recursion""" visited.add(vertex) result.append(vertex) for neighbor in self.graph[vertex]: if neighbor not in visited: self.dfs_recursive(neighbor, visited, result) return result # Usage g = Graph(5) g.add_edge(0, 1) g.add_edge(0, 2) g.add_edge(1, 2) g.add_edge(1, 3) g.add_edge(2, 4) print("DFS:", g.dfs(0)) # [0, 2, 4, 1, 3] print("BFS:", g.bfs(0)) # [0, 1, 2, 3, 4] visited = set() print("DFS Recursive:", g.dfs_recursive(0, visited, [])) # [0, 1, 2, 4, 3]
Real-World Applications:
  • Social networks (friend connections)
  • GPS navigation (shortest path)
  • Web page links (PageRank)
  • Network routing protocols
  • Game development (NPC pathfinding)
  • Dependency graphs in software

10. Heaps Intermediate

Definition

A heap is a specialized tree-based data structure that satisfies the heap property. It's a complete binary tree that can be efficiently implemented using an array.

Key Characteristics:

  • ✓ O(log n) insertion and deletion
  • ✓ O(1) access to min/max element
  • ✓ Array-based, space efficient
  • ✗ Not suitable for search
  • ✗ Only min or max at top

Types of Heaps:

  • Min Heap: Parent ≤ Children (smallest at root)
  • Max Heap: Parent ≥ Children (largest at root)
📌 Example 1: Min Heap Operations
import heapq # Min Heap using heapq (Python) min_heap = [] # Add elements heapq.heappush(min_heap, 5) heapq.heappush(min_heap, 3) heapq.heappush(min_heap, 7) heapq.heappush(min_heap, 1) print("Min Heap:", min_heap) # [1, 3, 7, 5] # Get minimum print(heapq.heappop(min_heap)) # 1 print(heapq.heappop(min_heap)) # 3 # Peek at minimum without removing print(min_heap[0]) # 5 # Create heap from list numbers = [5, 3, 7, 1, 9, 2] heapq.heapify(numbers) print("Heapified:", numbers) # [1, 3, 2, 5, 9, 7] # For max heap, negate values max_heap = [] heapq.heappush(max_heap, -5) heapq.heappush(max_heap, -3) heapq.heappush(max_heap, -7) print("Max Heap:", [-x for x in max_heap])
📌 Example 2: Heap Sort
import heapq def heap_sort(arr): """Sort array using heap""" # Create min heap heapq.heapify(arr) # Extract elements one by one sorted_arr = [] while arr: sorted_arr.append(heapq.heappop(arr)) return sorted_arr # Usage numbers = [5, 3, 7, 1, 9, 2, 4] print("Original:", numbers) print("Sorted:", heap_sort(numbers.copy())) # Or using heapsort directly numbers2 = [5, 3, 7, 1, 9, 2, 4] sorted_nums = sorted(numbers2) # Uses Timsort but can use heapq print("Sorted (built-in):", sorted_nums)

Common Algorithms Using Data Structures

Sorting Algorithms

Search Algorithms

  • Binary Search: Requires sorted array - O(log n)
  • DFS: Uses stack/recursion - O(V+E)
  • BFS: Uses queue - O(V+E)
  • Hash-based Search: Hash table - O(1) avg

  • Dijkstra: Shortest path - uses heap/priority queue
  • Floyd-Warshall: All pairs shortest paths - uses matrix
  • Prim/Kruskal: Minimum spanning tree - uses heap/disjoint set
  • Topological Sort: DAG - uses stack/queue

class LRUCache: """Least Recently Used Cache""" def __init__(self, capacity): self.capacity = capacity self.cache = {} # key -> value self.order = {} # key -> DNode self.head = None self.tail = None class Node: def __init__(self, key, value): self.key = key self.value = value self.prev = None self.next = None def get(self, key): if key not in self.cache: return -1 self._move_to_head(key) return self.cache[key] def put(self, key, value): if key in self.cache: self.cache[key] = value self._move_to_head(key) else: if len(self.cache) >= self.capacity: # Remove least recently used self._remove_tail() node = self.Node(key, value) self.cache[key] = value self.order[key] = node self._add_to_head(node) def _move_to_head(self, key): # Move node to head (most recently used) node = self.order[key] if node.prev: node.prev.next = node.next if node.next: node.next.prev = node.prev if node == self.tail: self.tail = node.prev node.prev = None node.next = self.head if self.head: self.head.prev = node self.head = node if not self.tail: self.tail = node def _add_to_head(self, node): node.prev = None node.next = self.head if self.head: self.head.prev = node self.head = node if not self.tail: self.tail = node def _remove_tail(self): if not self.tail: return key = self.tail.key if self.tail.prev: self.tail.prev.next = None self.tail = self.tail.prev del self.cache[key] del self.order[key] if not self.tail: self.head = None # Usage lru = LRUCache(3) lru.put(1, "a") lru.put(2, "b") lru.put(3, "c") print(lru.get(1)) # "a" lru.put(4, "d") # Removes key 2

💡 When to Use Which Data Structure

🔹 Need fast random access?

→ Use Array - O(1) access by index

🔹 Frequent insertions/deletions at ends?

→ Use Linked List or Deque - O(1) at ends

🔹 LIFO operations needed?

→ Use Stack - function calls, undo, parentheses matching

🔹 FIFO operations needed?

→ Use Queue - BFS, task scheduling, print jobs

🔹 Need key-value mapping with fast lookup?

→ Use Hash Table - O(1) average search

🔹 Unique elements only?

→ Use Set - eliminate duplicates, set operations

🔹 Need sorted data with frequent insertions/deletions?

→ Use BST or Balanced BST - O(log n) operations

🔹 Need to find min/max frequently?

→ Use Heap - O(log n) insert/delete, O(1) access min/max

🔹 Need to model relationships/connections?

→ Use Graph - social networks, maps, dependencies

🔹 Need string prefix matching/autocomplete?

→ Use Trie - O(m) search where m = string length

📊 Quick Reference Summary

Linear Data Structures

  • Array: Fixed/dynamic, fast access, slow insertion
  • Linked List: Dynamic, fast insertion, slow access
  • Stack: LIFO, O(1) push/pop
  • Queue: FIFO, O(1) enqueue/dequeue

Non-Linear Data Structures

  • Tree: Hierarchical, fast search in BST, organizing data
  • Graph: General structure, modeling relationships
  • Heap: Priority-based, efficient min/max extraction

Hash-based Data Structures

  • Hash Table: Fast key-value lookup
  • Set: Unique elements, set operations
