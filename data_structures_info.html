📚 Data Structures - Learning Guide

A comprehensive introduction to fundamental data structures and their applications

What Are Data Structures?

A data structure is a specialized format for organizing, processing, retrieving and storing data. It's a way to arrange data so that it can be accessed and modified efficiently. The choice of data structure can significantly impact the performance of your application.

Data structures are fundamental to computer science and programming. They provide a means to manage large amounts of data efficiently, enabling algorithms to work with data in structured and predictable ways.

1. Arrays

An array is a collection of elements, typically of the same type, stored in contiguous memory locations. Each element can be accessed by its index position.

Characteristics:

  • ✓ Fast access by index: O(1)
  • ✓ Simple to understand and implement
  • ✗ Fixed size (in most languages)
  • ✗ Slow insertion/deletion: O(n)
Example in Python:
numbers = [10, 20, 30, 40, 50] print(numbers[0]) # Output: 10 print(numbers[2]) # Output: 30 numbers.append(60) # Add element print(len(numbers)) # Output: 6

2. Linked Lists

A linked list is a linear data structure where elements (called nodes) are linked together using pointers or references. Each node contains data and a link to the next node.

Characteristics:

  • ✓ Dynamic size
  • ✓ Efficient insertion/deletion: O(1) if position known
  • ✗ Slow access: O(n)
  • ✗ Extra memory for pointers
Example in Python:
class Node: def __init__(self, data): self.data = data self.next = None # Create linked list: 1 -> 2 -> 3 head = Node(1) head.next = Node(2) head.next.next = Node(3) # Traverse current = head while current: print(current.data, end=" -> ") current = current.next # Output: 1 -> 2 -> 3 ->

3. Stacks

A stack is a linear data structure that follows the Last-In-First-Out (LIFO) principle. The last element added is the first one to be removed.

Characteristics:

  • ✓ Simple LIFO operations
  • ✓ O(1) push and pop operations
  • Used in function calls, undo functionality, expression evaluation
Example in Python:
# Using a list as stack stack = [] stack.append(1) # Push stack.append(2) # Push stack.append(3) # Push print(stack.pop()) # Output: 3 (LIFO) print(stack.pop()) # Output: 2 print(len(stack)) # Output: 1

4. Queues

A queue is a linear data structure that follows the First-In-First-Out (FIFO) principle. The first element added is the first one to be removed.

Characteristics:

  • ✓ Simple FIFO operations
  • ✓ O(1) enqueue and dequeue
  • Used in print queues, task scheduling, breadth-first search
Example in Python:
from collections import deque queue = deque() queue.append(1) # Enqueue queue.append(2) # Enqueue queue.append(3) # Enqueue print(queue.popleft()) # Output: 1 (FIFO) print(queue.popleft()) # Output: 2

5. Trees

A tree is a hierarchical data structure consisting of nodes connected by edges. It has a root node and each node can have multiple children. Trees are used extensively in databases, file systems, and algorithms.

Common Types:

  • Binary Tree: Each node has at most 2 children
  • Binary Search Tree: Left child < parent < right child
  • Balanced Tree: Height difference is minimized
Example in Python:
class TreeNode: def __init__(self, value): self.value = value self.left = None self.right = None # Create binary tree root = TreeNode(1) root.left = TreeNode(2) root.right = TreeNode(3) root.left.left = TreeNode(4) # Tree structure: # 1 # / \ # 2 3 # / # 4

6. Hash Tables (Dictionaries)

A hash table is a data structure that maps keys to values using a hash function. It provides very fast average-case lookup, insertion, and deletion.

Characteristics:

  • ✓ Average O(1) for search, insert, delete
  • ✓ Efficient key-value mapping
  • ✗ Unordered
  • ✗ Can have collisions
Example in Python:
# Dictionary (Hash Table) student = { "name": "John", "age": 20, "grade": "A" } print(student["name"]) # Output: John student["age"] = 21 # Update student["email"] = "john@example.com" # Add del student["grade"] # Delete

7. Graphs

A graph is a collection of nodes (vertices) and edges connecting pairs of nodes. It's used to represent networks, social connections, maps, and many other real-world relationships.

Types:

  • Directed Graph: Edges have a direction
  • Undirected Graph: Edges have no direction
  • Weighted Graph: Edges have weights/costs
Example in Python:
# Graph using adjacency list graph = { 'A': ['B', 'C'], 'B': ['A', 'D'], 'C': ['A', 'D'], 'D': ['B', 'C'] } # Traverse neighbors of A print(graph['A']) # Output: ['B', 'C']

Comparison of Data Structures

Data Structure Access Insert Delete Search
Array O(1) O(n) O(n) O(n)
Linked List O(n) O(1)* O(1)* O(n)
Stack O(n) O(1) O(1) O(n)
Queue O(n) O(1) O(1) O(n)
Binary Search Tree O(log n) O(log n) O(log n) O(log n)
Hash Table O(1) O(1) O(1) O(1)

* If position is known

💡 Tips for Choosing Data Structures

  • Need fast access by position? → Use Array
  • Frequent insertions/deletions? → Use Linked List
  • LIFO operations? → Use Stack
  • FIFO operations? → Use Queue
  • Key-value mapping? → Use Hash Table
  • Hierarchical data? → Use Tree
  • Network relationships? → Use Graph
